# TravelSetu — 4-Week Development Snapshot

This is a separate copy of the TravelSetu project prepared to demonstrate the **past four weeks of development work**.

The copy intentionally contains only the modules needed to demonstrate the Week-4 prototype stage. It does **not** contain the complete final project's collection of pages and styling.

Run:

```bash
python app.py
```

Then open `http://127.0.0.1:5000`.
